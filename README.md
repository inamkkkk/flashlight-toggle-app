# Flashlight App

A simple Flutter app that toggles the device's flashlight on and off.

## Features

- Toggle flashlight with a single button.
- Handles platform-specific permissions.

## Dependencies

- [permission_handler](https://pub.dev/packages/permission_handler)
- [torch_controller](https://pub.dev/packages/torch_controller)
- [provider](https://pub.dev/packages/provider)

## Getting Started

1.  Clone the repository.
2.  Run `flutter pub get` to install dependencies.
3.  Run the app on a physical device or emulator.

## Permissions

The app requires camera permission to access the flashlight. Make sure to grant the necessary permissions when prompted.
